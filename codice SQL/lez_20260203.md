## ISTRUZIONI DDL - definition


```sql

CREATE DATABASE its2026;

drop table IF EXISTS pokemon;

create table if NOT EXISTS pokemon (
    id int PRIMARY KEY AUTO_INCREMENT,
    `name` VARCHAR(20) not NULL,
    type1 VARCHAR(20) not null,
    type2 VARCHAR(20)
);
```


---

## ISTRUZIONI DML - manipulation

### CRUD su table

#### CREATE

```sql
INSERT INTO pokemon (name, type1, type2) VALUES ('Bulbasaur','Grass',NULL);
```

#### READ

```sql
SELECT type1, count(type1) as quantity 
from pokemon 
group by type1
order by quantity desc
;
```


#### UPDATE

```sql

update pokemon_pacco
set `Type 1` = 'Rock&Roll'
where `Type 1` = 'Rock';

update pokemon_pacco
set `Type 1` = 'Rock'
where `Type 1` = 'Rock&Roll';
```

#### DELETE

```sql
delete from pokemon where id = 2;
```
